# Evaluation labels

This folder is for **your** human relevance labels, created with `paperscout eval template` and filled in by you. None are included: labels must come from a person judging papers against their own research goal, and an assistant can't produce them honestly.

The JSON files hold your research interests. Commit them only if you're comfortable sharing them. The test suite uses separate synthetic labels that only exercise the metric code.

See `docs/evaluation.md` for the procedure.
